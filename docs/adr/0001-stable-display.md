# 画面の表示位置を安定させる

- 日付: 2026-10-28
- 状態: 採用

## 背景

読み込みや状態通知の追加・消失によって、利用中の本文や操作対象が動くと読み続けにくく、誤操作にもつながる。
これは複数のサービスに共通する利用体験の課題である。

## 判断

サービスの画面では、読み込み・通知・更新によって本文や操作位置が意図せず動かないように設計する。
通知の重要度に応じて、表示方法と持続時間を選ぶ。重要な状態は読める形で伝え、狭い画面や拡大時にも内容・操作を遮らないよう確認する。

## 代替案と理由

通常の文書フローに一時通知を追加すると、通知の出現・消失で本文が動きやすい。
固定表示やあらかじめ確保した領域などを、画面と通知の内容に応じて選ぶ。
すべての通知を短時間で消す方式は、重要な状態を見逃す可能性があるため一律には採用しない。

## 影響

各サービスの状態通知・読み込み・更新を見直す際の判断基準とする。既存サービスを一括変更したことは意味しない。
画面幅、拡大表示、読み上げ、通知が操作を遮らないことを対象ごとに確認する。
