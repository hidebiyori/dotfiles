# フォントは用途と既存の表示を優先して選ぶ

- 日付: 2026-11-06
- 状態: 採用

## 背景

読みやすい通常画面、表の一覧性、等幅文字による配置など、画面によって書体に求めることが異なる。
書体を変更すると字幅や行高が変わり、表の折り返しや一画面で見える情報量にも影響する。
同じフォント指定でも、端末にある書体と文字ごとの代替によって表示は異なる。

## 判断

通常画面は端末にあるサンセリフ体の共通指定を候補とし、既存画面にも用途に合えば取り入れる。
既存画面の一覧性・レイアウトや意図した等幅、個別のデザインを優先する。文字サイズは別に判断する。
選択と変更時の確認方法は [共通方針](../web-app-candidates.md#フォント指定の共通方針)に記す。

## 代替案と理由

- すべての画面を同じフォントへ置き換える案は、既存の表や文字配置を崩すおそれがあるため採らない。
- 一つのWebフォントを全画面に配布する案は、画面ごとの用途に加え、転送・取得失敗・表示位置への影響を個別に判断する必要があるため採らない。
- フォントを一切指定しない案も選べるが、通常画面にはサンセリフ体を共通候補として示し、検討しやすくする。

## 影響

共通の出発点と確認条件を設けても、既存アプリの変更や全端末で同じ見た目になることは意味しない。
変更が必要な場合は各プロジェクトの要件と対象端末を確認し、表示を比較する。
