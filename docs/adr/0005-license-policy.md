# 0005: 自作コードのライセンスを GPLv3 に揃える

- 日付: 2026-11-07
- 状態: 採用

## 背景

自作コードの改変版が配布されるとき、受け取った人にもソースを入手・改変・再配布する自由を残したい。
複数のリポジトリで、ライセンスや対象範囲の表示が異なっている。

## 判断

公開・非公開を問わず、自作のプログラムコードは `GPL-3.0-only` を基本とする。
ライセンス全文と対象範囲を各リポジトリに置き、文章・画像・利用者の投稿と第三者の著作物は個別に扱う。
既存の許諾と第三者の権利は維持する。配置と確認方法は [ライセンスの共通方針](../licensing.md) に記す。

## 代替案

- MIT: 再利用の条件が緩く、改変版を配布する人に同じ条件でのソース提供を求めない。
- AGPLv3: 改変したサーバーソフトウェアのネットワーク利用者にもソースを提供する条件がある。
  今回は配布時の共有を基本にする。
- `GPL-3.0-or-later`: 将来の GPL バージョンも利用者が選べる。現時点ではバージョン3を指定する。

## 影響と制約

私的利用やサーバー上の利用だけで公開が必須になるわけではなく、改良を元の作者へ返す義務もない。
非公開リポジトリでも、対象コードの受領者には GPLv3 の条件に従う再配布の権利がある。
過去に別の条件で受け取られた版の許諾は取り消せない。
